# LUKAZII Layer Lab

Online visual parameter sandbox for the LUKAZII Aggressive Visual 07 / VST visual workflow.

Open the tool with GitHub Pages after enabling Pages:

Settings → Pages → Deploy from a branch → main → /root

Expected URL:

https://thedogof.github.io/lukazii-layer-lab/

## Current version

`v0.4-online`

Features:

- Layer-based visual controls
- Separate visual and color/theme settings
- Audio-reactive preview with demo oscillator or uploaded audio
- Export JSON for Codex / VST integration
- Auto-save to browser localStorage

This repository is intended as the online tuning interface for LUKAZII visual design experiments.
